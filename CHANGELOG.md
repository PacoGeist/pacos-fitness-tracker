# What's new

## 1.5
- **Settings > App updates:** shows your version and opens the GitHub download page to get the newest one. The app still has no internet access.
- First version published on GitHub, with automatic builds.

## 1.4
- Renamed to **Paco's Fitness Tracker** (previously IronLog).

## 1.3
- Dark mode is now the default theme.

## 1.2
- **Bodyweight exercises** with sets and reps (seconds for holds like planks).
- **Built-in library** of 41 gym machines and 48 bodyweight exercises, each with its muscles.
- **Library** tab: search by name or muscle, filter by type, and add machines or exercises without logging a workout.

## 1.1
- **Theme setting:** Auto, Light or Dark.
- **Muscle diagrams** for every machine, plus the combined muscles for each workout. Muscles can be changed.

## 1.0
- First version: weight machines with sets and reps, treadmill time and distance, history tables and charts, copy a past workout to today, backup and restore.
